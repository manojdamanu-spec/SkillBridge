SkillBridge – Find Your Next Opportunity

SkillBridge is a student collaboration platform designed to connect students, discover opportunities, showcase skills, and collaborate on exciting projects.

🎯 About the Project

SkillBridge helps students turn their skills into real project experiences. Students can find projects, connect with teammates, and request to join projects that match their interests and abilities.

✨ Key Features

- Dashboard: View your project activities.
- Find Projects: Discover available student projects.
- Find Teammates: Connect with students who have different skills.
- My Requests: Track your project joining requests.
- My Profile: Showcase your skills and interests.
- Project Collaboration: Request to join projects and work together.

🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- HTML
- CSS
- JavaScript
- PostgreSQL

🚀 How to Run the Project

1. Clone the repository:
   
   git clone https://github.com/manojdamanu-spec/SkillBridge.git

2. Open the project folder.

3. Install dependencies:
   
   pip install -r requirements.txt

4. Run the application:
   
   python app.py

5. Open your browser and visit:
   
   https://skillbridge-1-tbl9.onrender.com/
